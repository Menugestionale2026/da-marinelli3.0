Configurazione

Solo per chi gestisce il sito · da fare una volta

  1. Su GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → solo il repository del menù.
  3. Permissions → Contents: Read and write. Scadenza: la più lunga disponibile.
  4. Incolla il token qui sotto e scegli la password che userà il locale.

Il token viene salvato nel sito cifrato con questa password: senza la password è inutilizzabile. Usa una password non banale.
